= ONTAP tools でネットワーク アクセスを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
デフォルトでは、ONTAP tools は、ネットワーク アクセスを設定しない限り、ESXi ホストから検出されたすべての IP アドレスをエクスポート ポリシーに自動的に追加します。エクスポート ポリシーを変更して、特定の IP アドレスからのアクセスのみを許可することができます。除外された ESXi ホストではマウント操作が失敗します。

.手順
. vSphere Clientにログインします。
. プラグインセクションのショートカットページで *NetApp ONTAP tools* を選択します。
. ONTAPツールの左側のペインで、*設定* > *ネットワーク アクセスの管理* > *編集* に移動します。
+
複数の IP アドレスを追加するには、リストをカンマ、範囲、Classless Inter-Domain Routing （CIDR） 表記、またはこれら 3 つの組み合わせで区切ります。

. [ 保存（ Save ） ] を選択します。
