= ONTAP Tools for VMware vSphereのクイックスタートガイド
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
このクイックスタートを使用して、ONTAP tools for VMware vSphere をセットアップします。

まずこれらのコアタスクを完了して、初期設定とプロビジョニングのために ONTAP tools を動作可能な状態にしてください。次に、環境および保護要件に基づいて、オプションのタスクを完了してください。

最初に、ONTAP tools for VMware vSphere を超小型（XS）シングルノード構成として導入し、NFS および VMFS データストアのコアサービスを提供します。サービスごとに追加のコンテナが必要な場合、より高い耐障害性が必要な場合、または vVols データストアと高可用性（HA）が必要な場合は、まずこのワークフローを完了してから拡張に進んでください。詳細については、link:../deploy/ha-workflow.html["HA導入ワークフロー"] を参照してください。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1つ"]導入計画
[role="quick-margin-para"]
お使いの環境が、サポートされているデプロイメントに対応できる状態であることを確認してください。vSphere、ONTAP、および ESXi ホストのバージョンが ONTAP tools のバージョンと互換性があることを確認してください。十分な CPU、メモリ、およびディスク容量を確保してください。セキュリティルールに基づいて、ネットワーク トラフィックを許可するためにファイアウォールやその他のセキュリティ制御を設定する必要がある場合があります。

[role="quick-margin-para"]
vCenter Server がインストールされており、アクセス可能であることを確認してください。

[role="quick-margin-list"]
* https://imt.netapp.com/matrix/#welcome["Interoperability Matrix Tool で確認してください"]
* link:../deploy/prerequisites.html["VMware vSphere の要件と構成の制限に対する ONTAP ツール"]
* link:../deploy/pre-deploy-checks.html["始める前に"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2つ"]ONTAP Tools for VMware vSphereの導入
[role="quick-margin-para"]
NFS および VMFS データストアの基本サービスを確立するために ONTAP tools アプライアンスを導入します。

[role="quick-margin-para"]
vVolsデータストアおよびHAの導入環境を拡張する予定がある場合は、まずこのワークフローを完了してください。ONTAP tools for VMware vSphere 10.6では、CPUホットアドおよびメモリホットプラグはデフォルトで有効になっています。

[role="quick-margin-para"]
デプロイ中は、*カスタマイズ テンプレート* フィールド、特にホスト名、ONTAP tools の IP アドレスの使用状況、および DNS 要件を注意深く確認してください。

[role="quick-margin-list"]
* link:../deploy/ontap-tools-deployment.html["ONTAP Tools for VMware vSphereの導入"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3つ"] vCenter クライアント プラグイン の登録とインストール
[role="quick-margin-para"]
vCenter クライアント プラグインを登録し、必要な権限とロールを適用するには、vCenter Server インスタンスを追加します。vCenter Server インスタンスを追加すると、ONTAP tools はリモート プラグインを登録し、カスタム プラグインおよび API 権限を適用し、カスタムロールを作成して、vSphere ユーザーインターフェイスにプラグインのショートカットを追加します。

[role="quick-margin-list"]
* link:../configure/add-vcenter.html["ONTAPツールにvCenter Serverインスタンスを追加する"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["4つ"]ストレージバックエンドを設定する
[role="quick-margin-para"]
ONTAP ストレージリソースを接続して、ONTAP tools がデータストアのプロビジョニングと管理を行えるようにします。ストレージバックエンドを ONTAP クラスタに追加します。マルチテナント環境で vCenter Server がテナント SVM に関連付けられている場合は、ONTAP tools Manager を使用してクラスタを追加します。次に、ストレージバックエンドを vCenter Server に関連付けて、その vCenter インスタンスのグローバルマッピングを作成します。

[role="quick-margin-para"]
ONTAP toolsのインターフェイスを使用して、クラスターまたはSVMのクレデンシャルを持つローカル ストレージ バックエンドを追加します。これらのストレージ バックエンドは、単一のvCenterに制限されます。クラスターのクレデンシャルをローカルで使用すると、関連付けられているSVMが、vVolまたはVMFS管理のためにvCenterに自動的にマッピングされます。SRAを含むVMFS管理において、ONTAP toolsはグローバル クラスターを必要とせずにSVMのクレデンシャルをサポートします。

[role="quick-margin-list"]
* link:../configure/add-storage-backend.html["ストレージバックエンドを追加します"]
* link:../configure/associate-storage-backend.html["ストレージバックエンドをvCenter Serverインスタンスに関連付ける"]
