= ONTAP tools Manager でオプションサービスを有効にする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools Manager を使用して、VASA Provider、vVols 構成のインポート、ディザスタリカバリ（SRA）などのオプションサービスを有効にします。

.手順
. WebブラウザからONTAP Tools Managerを起動します。 `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 導入時に指定したONTAP tools for VMware vSphere管理者のクレデンシャルを使用してログインします。
. 「概要」セクションで、「アプライアンス設定の編集」を選択します。
. 「サービス」セクションで、VASA プロバイダー、vVols 構成のインポート、および災害復旧（SRA）など、必要なオプションサービスを有効にします。
+
これらのサービスを初めて有効にする際は、VASA ProviderとSRAの認証情報を作成してください。

+
** これらの認証情報を使用して、vCenter Server で VASA Provider および SRA サービスを登録して有効化します。
** ユーザー名には、英字、数字、アンダースコアのみを使用できます。
** パスワードの長さは8文字以上256文字以下である必要があります。





NOTE: オプションのサービスを無効にする前に、ONTAP tools で管理されている vCenter Server インスタンスがそのサービスを使用していないことを確認してください。

+ 「vVols構成のインポートを許可」オプションは、VASA Providerサービスが有効な場合にのみ表示されます。このオプションを使用すると、ONTAP tools 9.xからONTAP tools 10.6へのvVolsデータの移行が可能になります。
