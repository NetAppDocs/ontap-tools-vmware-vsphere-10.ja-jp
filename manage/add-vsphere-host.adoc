= VMware vSphereホストをONTAPツールに追加する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
新しい VMware vSphere ホストを ONTAP tools for VMware vSphere に追加して、ホストのデータストアを管理および保護できます。

.手順
. VMware vSphere クラスターにホストを追加するには、 https://techdocs.broadcom.com/["Broadcom技術ドキュメント"]に従ってください。
. ホストを追加したら、ONTAP tools のメインメニューを開き、概要パネルで「検出」を選択するか、スケジュールされたホスト検出が完了するまでお待ちください。


.結果
新しいホストは、ONTAP tools for VMware vSphere によって検出および管理されるようになりました。ホスト上でデータストアを管理できるようになりました。
