= ONTAP toolsでNFSおよびVMFSデータストアをアンマウントする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
このタスクを使用して、ESXiホストからNFSまたはVMFSデータストアをアンマウントします。クラスタレベルのデータストアのアンマウントは、UIまたはAPIを通じてはサポートされていません。

ONTAP tools 10.6以降、保護されたVMFSデータストアのアンマウントはブロックされます。

.手順
. vSphere Clientにログインします。
. NFSまたはVMFSデータストアオブジェクトを右クリックし、*データストアのマウント解除*を選択します。
+
vSphereクライアントはダイアログボックスを開き、データストアをマウントしているESXiホストの一覧を表示します。データストアが保護されている場合、ONTAP toolsはリクエストをブロックし、データストアが保護されているためアンマウントできないというメッセージを表示します。

. データストアをアンマウントするESXiホストを1つ以上選択します。
+
データストアをすべてのホストからアンマウントすることはできません。代わりにデータストアの削除処理を使用することを推奨します。

. [アンマウント]*ボタンを選択します。
+
*データストアのマウント解除*オプションは、ホストが保護対象ホストクラスタの外に移動された場合にのみ使用できます。




NOTE: データストアが保護されている場合は、アンマウントする前に保護を解除する必要があります。

.次の手順
進捗状況は、[最近のタスク]パネルで追跡できます。
