= ONTAP toolsでVASA構成をクリーンアップする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools で VASA のクリーンアップを完了するには、次の手順を実行します。


NOTE: VASA のクリーンアップを開始する前に、vVols データストアを削除してください。

.手順
. 開いて `\https://OTV_IP:8143/Register.html`プラグインの登録を解除します。
. プラグインがvCenter Serverで使用できなくなったことを確認します。
. ONTAP tools for VMware vSphere 仮想マシン（VM）をシャットダウンします。
. ONTAP Tools for VMware vSphere VMを削除します。
