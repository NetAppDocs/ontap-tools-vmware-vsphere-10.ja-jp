= ONTAP tools で仮想マシンを vVols データストアに移行する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
仮想マシンを NFS または VMFS データストアから仮想ボリューム（vVols）データストアに移行して、ポリシーベースの VM 管理やその他の vVols 機能を使用できます。

.作業を開始する前に
移行予定の仮想マシン上でVASA Providerが実行されていないことを確認してください。VASA Providerを実行している仮想マシンをvVolsデータストアに移行すると、vVolsデータストア上の仮想マシンの電源オンを含む管理操作を実行できなくなります。

.タスクの内容
NFS または VMFS データストアからvVolsデータストアに移行する場合、vCenter Server はvStorage APIs for Array Integration （VAAI）を使用して、VMFS データストアから移動されたデータのオフロードを行いますが、NFS VMDK ファイルからの移動データのオフロードは行いません。VAAI によるオフロードは通常、ホストの負荷を軽減します。

.手順
. 移行する仮想マシンを右クリックし、*[移行]*を選択します。
. [ストレージのみを変更]*を選択し、*[次へ]*を選択します。
. 移行するデータストアの機能に一致する仮想ディスク形式、VM ストレージ ポリシー、および vVol データストアを選択します。
. 設定を確認し、*[終了]*を選択します。
