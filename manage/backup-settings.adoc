= ONTAPツールのバックアップ設定を編集する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere 10.5以降、バックアップはデフォルトで有効になっており、10分ごとに実行されます。バックアップを無効にしたり、バックアップの頻度を変更したりできます。

バックアップを無効にしないでください。無効にすると、ONTAP tools が低い目標復旧時点（RPO）を維持できなくなります。バックアップを無効にしても、既存のバックアップ ファイルは削除されません。バックアップの頻度は、10 分から 60 分の間の値に変更できます。

.手順
. WebブラウザからONTAP Tools Managerを起動します。 `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. 導入時に指定したONTAP tools for VMware vSphere管理者のクレデンシャルを使用してログインします。
. *設定* > *バックアップ* > *編集* オプションを選択します。
. 編集ウィンドウで、バックアップを無効にするか、バックアップの頻度を変更します。
