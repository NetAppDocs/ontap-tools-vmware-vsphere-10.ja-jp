= バックアップからONTAP tools for VMware vSphereをリカバリする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
データストアに保存されているバックアップファイルを復元することで、ONTAP tools for VMware vSphere を回復します。ONTAP tools for VMware vSphere 10.5 以降、バックアップはデフォルトで有効になっているため、アプライアンスの再デプロイや復旧が必要な場合でも、通常は最新のバックアップが利用可能です。

ONTAP tools for VMware vSphere 仮想マシンをデプロイするデータストアには、バックアップファイルが保存されます。ONTAP tools の IP アドレスにちなんで名付けられたフォルダには、最新のバックアップファイル 2 つ（_OTV_backup_1.tar.enc_ および _OTV_backup_2.tar.enc_）と、最新のバックアップを識別する情報ファイル（_OTV_backup_info.txt_）が保存されます。

新しい仮想マシンが同じONTAPツール IP アドレスを使用し、有効なサービス、ノード サイズ、HA モードなどの初期システム構成と一致していることを確認します。

.手順
. 元の仮想マシンのデータストアからローカル システムにバックアップ ファイルをダウンロードします。
+
.. ストレージ セクションに移動し、仮想マシンのバックアップ ファイルが含まれているデータストアを選択します。
.. [ファイル]*セクションを選択します。
.. 必要なバックアップ ディレクトリをダウンロードします。


. 既存の仮想マシンの電源をオフにします。次に、元のデプロイメントと同じ OVA ファイルを使用して新しい仮想マシンをデプロイします。
. vCenter Serverにログインします。
. 新しくデプロイされた ONTAP tools VM を見つけて、Web コンソールを起動します。
.  `maint`の資格情報を使用してログインします。
. と入力 `4`して*[Support and Diagnostics]*を選択します。
. と入力 `2`して*[リモート診断アクセスを有効にする]*オプションを選択し、診断アクセス用の新しいパスワードを作成します。
. ダウンロードしたディレクトリからバックアップ ファイルを選択します。最新のバックアップを識別するには、_OTV_backup_info.txt_ ファイルを参照してください。
. 次のコマンドを使用して、バックアップ ファイルを新しい仮想マシンに転送します。プロンプトが表示されたら、診断パスワードを入力します。
+
[listing]
----
scp <OTV_backup_X.tar.enc> diag@<node_ip>:/home/diag/system_recovery.tar.enc
----
+

NOTE: コマンドで指定されている保存先パスとファイル名（/home/diag/system_recovery.tar.enc）は変更しないでください。

. バックアップ ファイルが転送されたら、診断シェルにログインして次のコマンドを実行します。
+
[listing]
----
sudo perl /home/maint/scripts/post-deploy-upgrade.pl -recovery
----
+
ログは_/var/log/otvng/post-deploy-upgrade.log_ファイルに記録されます。



リカバリが完了すると、 ONTAPツールによってサービスと vCenter オブジェクトが復元されます。
