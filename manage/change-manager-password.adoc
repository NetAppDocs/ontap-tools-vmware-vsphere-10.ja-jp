= ONTAP tools Managerのパスワードの変更
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理者パスワードは、ONTAP tools Manager で変更できます。

.手順
. WebブラウザからONTAP Tools Managerを起動します。 `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. ONTAP tools for VMware vSphere管理者認証情報を使用してログインします。
. 右上隅にある「管理者」アイコンを選択し、「パスワードの変更」を選択してください。
. 「パスワードの変更」ダイアログボックスに、古いパスワードと新しいパスワードを入力します。そこに表示されているパスワード要件を確認してください。
. 変更を適用するには、[*変更*] を選択します。
