= ONTAP toolsでデータストアを削除する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
vCenter ServerでONTAP toolsを使用して、NFS、VMFS、またはvVolsデータストアを削除するには、このタスクを使用します。削除の動作とクリーンアップ オプションは、データストアのタイプによって異なります。

.NFSおよびVMFSデータストアの削除動作
* 仮想マシンで使用されているデータストアは削除できません。
* 保護対象ホストクラスタには、追加の保護制約が適用されます。


.vVols データストアの削除動作
vVols データストアでは、以下の処理が実行されます：

* vVol コンテナがマウント解除されました。
* igroupが使用されていない場合、そのイニシエータはigroupから削除されます。
* vVol コンテナが削除されます。
* フレックス ボリュームはストレージ アレイ上に残ります。


vVolsデータストアの場合、選択したデータストアにvVolsが存在しない場合にのみ、データストアを削除できます。

.作業を開始する前に
* データストアが仮想マシンによって使用されていないことを確認してください。
* データストアが保護されたホストクラスタに属しているかどうかを確認してください。
* データストアの削除時に、ONTAPクラスター上のバッキングボリュームを削除するかどうかを決定します。


[cols="1,1,2,2"]
|===
| データストアタイプ | 削除してもらえますか？ | 主要な遮断条件 | ONTAPクリーンアップオプション 


| NFS | はい | データストアは仮想マシンによって使用されています。 | 該当する場合は、*[ONTAP クラスター上のボリュームを削除]* を選択できます。 


| VMFS | はい | データストアは仮想マシンによって使用されているか、ホスト クラスタの保護制約が適用されています。 | *ONTAP クラスタのボリュームを削除*を選択できます。ONTAP ストレージ上の保護されたホスト クラスターでは、ONTAP からのボリュームの削除はサポートされていません。 


| vVol | はい、条件付きで | 1つ以上のvVolsがデータストア上に存在します。 | ONTAP からボリュームを削除するオプションを選択できます。ただし、ASA r2 では、このワークフローからの ONTAP のバッキングボリュームの削除はサポートされていません。 
|===
.手順
. vSphere Clientにログインします。
. ホスト システム、ホスト クラスター、またはデータ センターを右クリックし、* NetApp ONTAPツール* > *データストアの削除* を選択します。
+

NOTE: 仮想マシンが使用するデータストアは削除できません。削除する前に、仮想マシンを別のデータストアに移動してください。

+

NOTE: データストアが保護されたホストクラスタの一部である場合は、削除する前に保護制約を確認してください。

+
.. NFSまたはVMFSデータストアの場合、そのデータストアを使用している仮想マシンの一覧が表示されたダイアログボックスが表示されます。
.. VMFSデータストアに関連付けられている仮想マシンがない場合、確認ダイアログが表示されます。ホストクラスタ保護が有効になっており、Automated Failover Duplex （AFD）の関係が存在する場合、セカンダリストレージ要素をクリーンアップできます。
.. ASA r2 ストレージシステム上の保護された VMFS データストアの場合は、削除する前に保護を解除してください。ONTAP 9.17.1 および ONTAP tools for VMware vSphere 10.5 以降では、保護されたデータストアを削除できます。
+
Automated Failover Duplex （AFD）を使用した最後のデータストア削除の場合、ONTAP tools に次のメッセージが表示されます：*データストアは保護されています。削除前に保護が解除されます。*

+
保護グループ内の最後の保護データストアを削除すると、ONTAP tools には、最後のデータストアを削除するとデータストアが保護されなくなるというメッセージが表示されます。

.. vVolsデータストアの場合、 vVolsが存在しない場合にのみデータストアを削除できます。  *データストアの削除* ダイアログ ボックスには、 ONTAPクラスターからボリュームを削除するオプションが含まれています。
.. ASA r2ストレージシステム上のvVolsデータストアでは、*データストアの削除*オプションを使用してONTAPからバッキングボリュームを削除することはできません。


. ONTAPストレージの元のボリュームを削除するには、* ONTAPクラスタのボリュームを削除する*を選択します。
+

NOTE: 保護されたホスト クラスタの一部である ONTAP ストレージ上の VMFS データストアの場合、ONTAP クラスタからボリュームを削除することはできません。



NFS、VMFS、またはvVolsデータストアを削除すると、親igroupはONTAPシステムに残ります。いずれのLUNにもマッピングされていない子igroupは自動的に削除されます。ONTAP toolsは、マッピングされていないデフォルトの親igroupを削除するために、毎日クリーンアップを実行します。カスタム親igroupはONTAPで手動で削除してください。ONTAP toolsは、古い親igroupを再利用できません。
