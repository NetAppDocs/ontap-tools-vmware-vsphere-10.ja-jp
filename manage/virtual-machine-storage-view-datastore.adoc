= ONTAP tools で仮想マシンのストレージの詳細を表示する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージビューを使用して、仮想マシンに関連付けられているvVolsを確認します。


NOTE: このビューは、ONTAP tools for VMware vSphere が管理するvVolsデータストアからのディスクが少なくとも 1 つある VM に適用されます。

.手順
. vSphere Client から仮想マシンに移動します。
. 右側のペインで* Monitor *タブを選択します。
. *NetApp ONTAP tools* > *ストレージ* を選択します。*ストレージ* の詳細が右側のペインに表示されます。VM上の vVols のリストを確認できます。
+
「列の管理」オプションを使用すると、列の表示/非表示を切り替えることができます。
