= 他のONTAP toolsノードでSSHを起動します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphereをアップグレードする前に、環境内の他の各ノードでSSHを起動してください。

.作業を開始する前に
vCenter Server インスタンスの VASA プロバイダ拡張機能を有効にします。

.タスクの内容
アップグレードする前に、各ノードでこの手順を繰り返します。

.手順
. vCenter Serverにログインします。
. ONTAP tools ノード VM を見つけて、Web コンソールを起動します。
.  `maint`の資格情報を使用してログインします。
. と入力 `4`して*[Support and Diagnostics]*を選択します。
. Enter `1`を押して「診断シェルへのアクセス」を選択してください。
. 入力するコマンド `y` 続行してください。
. コマンドを実行します `sudo systemctl restart ssh`。
