= ONTAP tools で VMFS データストアを保護する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
保護対象となるVMFSデータストアを保護グループに追加することで、そのデータストアを保護します。

.作業を開始する前に
* データストアがiSCSIまたはFCプロトコルを使用していることを確認してください。
* vSphere の管理者権限があることを確認してください。
* データストアが既に保護グループに属していないことを確認してください。


.手順
. vSphere Clientにログインします。
. ホストクラスタを選択し、*データストア*を選択します。
. 保護する対象の VMFS データストアを右クリックし、*NetApp ONTAP tools* > *保護* を選択します。
+
システムは、データストアが保護の対象となるかどうかを確認します。データストアが保護の対象となる場合、保護ワークフローは続行されます。データストアが不適格な場合は、理由を示すメッセージが表示され、処理を続行できません。

. データストアを既存の保護グループに追加するか、新しい保護グループを作成するかを選択してください。
+
.. 既存の保護グループを使用する場合は、保護グループを選択して続行してください。
.. 新しい保護グループを作成するには：
+
... 保護グループの名前を指定してください。
... [関係の追加]*を選択します。
... [ SnapMirror関係の追加]*ウィンドウで、*[ターゲットStorage VM]*と*[ポリシー]*タイプを選択します。
+
ポリシータイプは *非同期* または *AutomatedFailOverDuplex* です。

+
*AutomatedFailOverDuplex*を選択する場合は、ONTAP tools for VMware vSphereがデプロイされているのと同じvCenter Serverに、ターゲット ストレージ VMをストレージ バックエンドとして追加してください。

+
*AutomatedFailOverDuplex* の場合は、均一または非均一のホスト構成を選択します。「ユニフォームホスト構成」トグルを選択すると、ホストイニシエータグループ構成がターゲットサイトに暗黙的にレプリケートされます。詳細については、link:../concepts/ontap-tools-concepts-terms.html["主要な概念と用語"]を参照してください。

... 非均一なホスト構成を選択した場合は、クラスタ内の各ホストに対してホストアクセス（送信元/送信先）を選択してください。




. 保護ワークフローを開始するには、*OK* を選択します。


.結果
データストアは、選択した保護グループに表示されます。保護ステータスは、ONTAP tools プラグインから表示および管理できます。
