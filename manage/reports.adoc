= ONTAP tools for VMware vSphere レポート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere プラグインは、ONTAPストレージを基盤とする仮想マシンとデータストアの監視に役立つレポートを提供します。レポートを表示するには、vSphere Clientのショートカットセクションで ONTAP tools for VMware vSphere プラグインのアイコンを選択し、「レポート」タブを選択します。

仮想マシンレポートには、ONTAP ストレージベースのデータストアに少なくとも 1 つのディスクを持つ検出済みの仮想マシンとパフォーマンス指標が一覧表示されます。VM レコードを展開すると、そのディスクに関するすべてのデータストア情報が表示されます。

データストアレポートには、ONTAP tools for VMware vSphere が検出した ONTAP ストレージを使用するデータストアと、パフォーマンス指標が一覧表示されます。

「列の管理」オプションを使用すると、列の表示/非表示を切り替えることができます。
