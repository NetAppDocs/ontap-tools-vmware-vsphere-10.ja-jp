= ONTAP tools for VMware vSphere レポート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphereプラグインは、ONTAPストレージを基盤とする仮想マシンとデータストアの監視に役立つレポートを提供します。これらのレポートを表示するには、vCenterクライアントのショートカット セクションでONTAP tools for VMware vSphereプラグイン アイコンを選択し、次に「レポート」タブを選択します。

仮想マシンレポートには、ONTAP ストレージベースのデータストアに少なくとも 1 つのディスクがある検出済みの仮想マシンと、パフォーマンス指標が一覧表示されます。VM レコードを展開すると、インターフェースにディスク関連のデータストア情報がすべて表示されます。

データストアレポートには、ONTAP tools for VMware vSphere が検出した ONTAP ストレージを使用するデータストアと、パフォーマンス指標が一覧表示されます。

[列の管理]オプションを使用すると、さまざまな列の表示と非表示を切り替えることができます。
