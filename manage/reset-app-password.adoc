= ONTAP tools でアプリケーションユーザーのパスワードをリセットする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphereにおいて、VASA ProviderおよびSRAがvCenter Serverに登録するために使用するアプリケーション ユーザーのパスワードをリセットします。

.手順
. ウェブブラウザを開いて、 `https://<ONTAPtoolsIP>:8443/virtualization/ui/`に移動します。
. ONTAPツールの導入時に設定された管理者の認証情報を使用してログインします。
. サイドバーから*設定*を選択します。
. *VASA/SRA 資格情報* ページで、*パスワードのリセット* を選択します。
. 新しいパスワードを入力して確認します。
. 新しいパスワードを適用するには、[*リセット*] を選択します。
