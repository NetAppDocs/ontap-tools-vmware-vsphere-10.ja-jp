= ONTAP toolsでアプリケーションユーザーのパスワードをリセットする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SRAおよびVASAプロバイダーのvCenter ServerへのONTAP tools for VMware vSphere登録に必要なアプリケーションユーザーパスワードをリセットします。

.手順
. Web ブラウザを開き、次の場所に移動します。 `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. ONTAPツールの導入時に設定された管理者の認証情報を使用してログインします。
. サイドバーから*設定*を選択します。
. *VASA/SRA 資格情報* ページで、*パスワードのリセット* を選択します。
. 新しいパスワードを入力して確認します。
. 新しいパスワードを適用するには、[*リセット*] を選択します。
