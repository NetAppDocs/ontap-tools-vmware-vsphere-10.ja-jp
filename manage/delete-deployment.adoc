= ONTAP toolsをアンインストールした後、FlexVolボリュームを削除する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
専用の ONTAP クラスターに ONTAP tools for VMware vSphere をデプロイすると、デプロイメントによって多くの未使用の FlexVol ボリュームが作成されます。ONTAP tools を削除した後、パフォーマンスへの影響を避けるために、未使用の FlexVol ボリュームを削除してください。

.手順
. ONTAP tools management node VM から ONTAP tools for VMware vSphere のデプロイメントタイプを確認します。デプロイメントタイプを確認するには、次のコマンドを実行します：_cat /opt/netapp/meta/ansible_vars.yaml | grep -i protocol_
+
デプロイメントでiSCSIを使用している場合は、igroupも削除してください。

. FlexVolボリュームのリストを取得します。_kubectl で永続ボリュームを記述 | grep で内部名を記述 | awk -F'=' '{print $2}'_
. vCenter ServerからVMを削除します。を参照してください https://techdocs.broadcom.com/us/en/vmware-cis/vsphere/vsphere/8-0/vsphere-virtual-machine-administration-guide-8-0/managing-virtual-machinesvsphere-vm-admin/adding-and-removing-virtual-machinesvsphere-vm-admin.html#GUID-376174FE-F936-4BE4-B8C2-48EED42F110B-en["VMおよびVMテンプレートの削除と再登録"]。
. FlexVolボリュームを削除します。参照 https://docs.netapp.com/us-en/ontap/volumes/delete-flexvol-task.html["FlexVol ボリュームを削除します"]。ボリュームを削除するには、CLI コマンドに正確なFlexVol volume名を入力します。
. iSCSI 展開の場合は、ONTAP ストレージバックエンドから SAN igroup を削除します。参照 https://docs.netapp.com/us-en/ontap/san-admin/manage-san-initiators-task.html["SANイニシエータとigroupを表示および管理します"]。
