= ONTAP tools で保護グループを管理する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
このタスクを使用して、ONTAP tools の保護グループページから保護グループとその関係を表示、編集、および削除します。

.作業を開始する前に
* vSphere の管理者権限があることを確認してください。
* ONTAP tools のユーザーアカウントに保護グループを管理する権限があることを確認してください。



IMPORTANT: 保護設定を編集または削除する前に、ダイアログに表示される警告メッセージを確認してください。関係を削除すると、バックアップと整合性の動作に影響する可能性があります。

.タスクの内容
* ONTAP tools は、選択した ONTAP tools インスタンスのローカル保護レコードを更新します。
* 「関連付けられたストレージ要素を削除」を選択した場合、ONTAP tools は保護グループ内のストレージ要素を削除します。
* 「関連付けられたストレージ要素を削除」を選択しない場合は、ONTAP で宛先側の関係とストレージ要素を手動で削除してください。




[[view-protection-groups]]
== 保護グループを表示する

.手順
. ONTAP tools プラグインで、*Protection* > *Protection groups* に移動します。
+
保護グループ一覧には、整合性グループ、SnapMirror ポリシー、保護されたデータストアなどの関連関係が表示されます。

. 保護グループの詳細（保護対象データストアの数を含む）を確認してください。




[[edit-protection-group-relationships]]
== 保護グループの関係を編集する

.手順
. ONTAP tools プラグインで、*Protection* > *Protection groups* に移動します。
. 編集する保護グループの横にある縦の省略記号（3つの点）を選択します。
. 「保護グループの編集」を選択します。
. 関係設定を更新する：
+
.. 保護グループに自動フェールオーバーデュプレックス（AFD）関係が設定されている場合、非同期関係を追加できます。
.. 保護グループが非同期関係にある場合、自動フェールオーバーデュプレックス（AFD）関係を追加できます。
.. 保護グループに自動フェールオーバーデュプレックス（AFD）と非同期の両方の関係が設定されている場合、*保護グループの編集*ウィンドウからどちらか一方の関係を削除できます。
.. 各保護グループは、自動フェイルオーバーデュプレックス（AFD）関係と非同期関係をそれぞれ1つずつしか持つことができません。
.. 別のAFD関係を使用するには、既存のAFD関係を削除してから、新しいAFD関係を追加してください。
.. *保護グループの編集*ウィンドウで既存の関係を削除する場合は、関係を削除するとバックアップと整合性に影響が出る可能性があるという警告を確認してください。
.. 「保護グループの編集」ウィンドウで非同期関係を削除しても、宛先側のストレージリソースは自動的に削除されません。宛先側の関係とストレージ要素を ONTAP で手動で削除してください。





NOTE: 編集操作は、サポートされている関係設定に限定されます。変更を保存する前に、保護ポリシーとワークフロー要件を確認してください。



[[remove-a-protection-group]]
== 保護グループを削除する

.手順
. ONTAP tools プラグインで、*Protection* > *Protection groups* に移動します。
. 削除する保護グループの横にある縦の省略記号（3つの点）を選択します。
. 「保護を解除」を選択します。
. 「保護の削除」ダイアログで、ホストクラスタの保護を削除するとデータストアが保護されなくなるというメッセージを確認してください。
. オプション：保護グループ内のストレージ要素を削除するには、「関連付けられたストレージ要素を削除」（クリーンアップ アーティファクト）を選択します。
+
ストレージ要素には、整合性グループ、ボリューム、ストレージユニット、スナップショットなどが含まれます。

. 「関連付けられたストレージ要素を削除する」を選択しない場合、ONTAP tools はローカル保護レコードのみを削除します。ONTAP で宛先側の関係とストレージ要素を手動で削除してください。


[cols="1,1,1,1"]
|===
| 関係タイプ | スコープを削除 | 自動クリーンアップ | 手動クリーンアップが必要です 


| 自動フェイルオーバーデュプレックス（AFD） | どちらかのサイトで保護設定を削除すると、両方のサイトでその関係が削除されます。 | 関係レコードはワークフローの一環として削除されます。 | *関連するストレージ要素を削除する* を選択しない場合は、必要に応じて残りのストレージ要素を手動で削除してください。 


| 非同期 | 削除はローカルの ONTAP tools インスタンスにのみ適用されます。サイト間削除は利用できません。 | ローカル保護レコードが削除されます。 | ONTAP で宛先側の関係とストレージ要素を手動で削除します。 
|===
.結果
* ONTAP tools は、選択した保護グループのローカル保護レコードを削除します。
* 「関連付けられたストレージ要素を削除する」を選択した場合、ONTAP tools は保護グループ内の選択されたストレージ要素を削除します。
* 宛先側の関係やストレージ要素が残っている場合は、ONTAP で手動で削除してください。
